TANG TERMINAL 1.0.0
===================

FASTEST START

macOS:  Double-click install-macos.command, then use the Desktop shortcut.
Windows: Right-click install-windows.ps1 and run with PowerShell, or see the
         command in the main README.md one folder above.
Offline: Double-click index.html. Demo data and layout persistence work without
         a server or internet connection.

Move the browser window to your chosen monitor, then select FULLSCREEN.

For full setup, Ollama, data, privacy, and development details, read README.md
in the project root.
