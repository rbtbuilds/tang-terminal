# Changelog

All notable changes to TANG Terminal are recorded here.

## 3.2.1 — 2026-08-26

- Send Finnhub credentials in the authentication header so keys never enter upstream URLs or request logs.
- Match the live earnings request to the configured US-calendar entitlement and document international limits.
- Add a tested capability map for future Finnhub integrations.

## 3.2.0 — 2026-08-26

- Added the Overview earnings radar with upcoming event timing and analyst EPS/revenue estimates.
- Added an optional server-side Finnhub adapter with one-hour caching and no browser credential exposure.
- Added a plainly labelled beat/miss lean derived from at most four recent surprise outcomes.
- Added a simulated offline/demo earnings calendar and a v2-to-v3 workspace migration that preserves existing layouts.

## 3.1.1 — 2026-08-26

- Added continuous 3–12-column widget width resizing with per-workspace persistence.
- Added durable project direction and contribution documentation.

## 3.1.0 — 2026-08-26

- Added Overview news, movers, educational setups, SEC insider activity, and Congressional disclosures.
- Added the persistent collapsible Ollama assistant dock.
- Added disclosure freshness and reporting-delay labels.

## 3.0.0 — 2026-08-25

- Rebuilt the dashboard as five linked workspaces with collision-free grid layout.
- Added global symbol search, persistent watchlist, instrument research, energy and commodity panels.
- Added the Natural Earth shipping map and optional server-side AISStream positions.

Earlier development releases established the offline shell, quote adapters, Ollama integration, typography controls, and initial market widgets.
